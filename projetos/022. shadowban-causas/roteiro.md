## Fala completa (português correto: roteiro, legenda e telas)

| Bloco | Fala |

| Gancho (Luísa) | Essas quatro coisas te dão shadowban, e você pode estar fazendo uma agora. |

| 1. Sorteio | Primeira: sorteio. Post que promove sorteio ou concurso não é recomendado. |
| 2. Isca | Segunda: isca de engajamento. Post feito só pra forçar interação, tipo "marca três amigos pra ganhar". Pedir pra comentar uma palavra pra receber o link pode, o próprio Instagram já disse. |

| 4. Link | Quarta: link pra site que vive de clique vindo do Instagram. |
| O que fazer | E aí, o que fazer? Se o alcance caiu, abre o Status da conta e vê qual post está marcado. Edita ou apaga esse post. E se foi repost, para de repostar: depois de trinta dias abaixo de dez, o perfil volta a ser recomendado. |
